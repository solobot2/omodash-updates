# Omodash updates

Signed APK updates for Omodash, an Android dashboard launcher for OMODA and EXEED head units.

[Download the latest APK](https://github.com/solobot2/omodash-updates/releases/latest/download/omodash.apk) · [All releases](https://github.com/solobot2/omodash-updates/releases)

## First installation after moving the update feed

1. Download **Omodash 0.0.34 or newer** from Releases.
2. Install it manually over your existing Omodash release installation. Keep the app installed to preserve settings and permissions.
3. Open **Settings → Updates** for future versions. No GitHub login is required in the app.

The application ID is `win.solobot.omodash`. Official updates use the same signing certificate as previous Omodash releases.

## Release files

- `omodash.apk` — signed Android application.
- `update.json` — version, compatibility, download URL, checksum and signing certificate fingerprint used by the app.
- `SHA256SUMS.txt` — APK checksum for manual verification.

This repository contains update packages and this README. Application source code, R8 mappings, signing keys and local configuration are not published here. GitHub's source-code archives contain this repository's documentation, not the application source.
